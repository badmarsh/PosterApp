# ATLAS TileCal HL-LHC Poster

This folder contains all the files necessary to compile the LaTeX poster.

## How to compile

### Option 1: Overleaf (Recommended for ease of use)
1. Zip this entire folder (or just use the one you received).
2. Go to overleaf.com and click "New Project" -> "Upload Project".
3. Upload the zip file. Overleaf will automatically detect `main.tex` and compile it for you.

### Option 2: Local LaTeX installation
If you have a local LaTeX distribution (like TeX Live or MiKTeX) installed:
Run the following command in your terminal:
`pdflatex main.tex`
`pdflatex main.tex`
(Running it twice ensures proper alignment of blocks).
